# Source

This courtyard world comes from the user-generated Kimi courtyard run in the
`gaoypeng/3dcodeverse` harness. `scene.js` and its reachable relative
runtime dependencies were copied from that run with their source bytes
preserved. No live generation or model call is required to run this world.

`LICENSE` contains the license text from the copied harness repository. It
applies to the harness material as documented there; this file does not make
a separate licensing claim for generated assets.
